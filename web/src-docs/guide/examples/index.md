# Examples

The examples directory in the source repository contains practical demonstrations:

| Example                                                                               | Description                                     |
| ------------------------------------------------------------------------------------- | ----------------------------------------------- |
| [basic-read-build-meta](../../../../examples/web/basic-read-build-meta/README.md)         | Read CSV by building metadata in code           |
| [basic-read-load-meta](../../../../examples/web/basic-read-load-meta/README.md)           | Read CSV by loading XML metadata                |
| [basic-write](../../../../examples/web/basic-write/README.md)                             | Write CSV with automatic quoting                |
| [build-meta-with-sequences](../../../../examples/web/build-meta-with-sequences/README.md) | Build metadata for files with sequences         |
| [count-records](../../../../examples/web/count-records/README.md)                         | Efficiently count records without reading data  |
| [read-events](../../../../examples/web/read-events/README.md)                             | Use event hooks during reading                  |
| [read-sequence](../../../../examples/web/read-sequence/README.md)                         | Read files with sequences (conditional fields)  |
| [read-sequence-ordinal](../../../../examples/web/read-sequence-ordinal/README.md)         | Read sequences using ordinals for performance   |
| [sequences-with-readback](../../../../examples/web/sequences-with-readback/README.md)     | Work with repeating groups                      |
| [write-comments](../../../../examples/web/write-comments/README.md)                       | Add comment lines to output                     |
| [write-declared](../../../../examples/web/write-declared/README.md)                       | Create files with declaration headers           |
| [write-events](../../../../examples/web/write-events/README.md)                           | Use event hooks during writing                  |
| [write-headings](../../../../examples/web/write-headings/README.md)                       | Write heading lines                             |
| [write-sequence](../../../../examples/web/write-sequence/README.md)                       | Write files with sequences (conditional fields) |
| [write-sequence-events](../../../../examples/web/write-sequence-events/README.md)         | Write sequences using event-driven approach     |

## Running Examples

From within the examples directory:

```bash
# Run all examples
npm run all

# Run individual example
npm run basic-write
```
